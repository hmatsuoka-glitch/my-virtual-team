### 2026-06-13
- **用語再確認：「見積原価」「実行予算」「発生原価」は原価管理の3階層で混同厳禁**。見積原価＝受注前に積算した原価（利益計画の起点）、実行予算＝受注後に工事着手前に組み直す社内の原価目標（現場の予実管理の基準）、発生原価＝実際に支払・計上された原価。どっと原価の予実対比は「実行予算 vs 発生原価」であり、見積原価と比較すると受注後の原価低減努力が見えなくなる。クライアント説明時はどの原価を指すか必ず特定する
- **用語再確認：「工事進行基準/工事完成基準」は旧用語で、現行の収益認識会計基準では「履行義務の充足に係る進捗度に基づく収益認識（原価比例法等）」が正式な枠組み**。進捗度を合理的に見積れない場合は「原価回収基準」を適用。お役立ちツール_工事進行基準編.pdfの用語が旧基準ベースの場合、上場系・会計監査対象のクライアントには現行基準の呼称で補足する（※現行基準の詳細は資料外の一般知識）
- **用語再確認：インボイス制度の「経過措置」は免税事業者からの仕入に対する段階的控除のこと**。免税事業者（適格請求書発行事業者でない一人親方等）からの課税仕入は、本来仕入税額控除不可だが、経過措置により一定割合（80%→50%と段階縮小、最終的に控除廃止）の控除が認められる。建設業では下請・一人親方に免税事業者が多く、元請の控除減＝実質コスト増になる構図が「建設業インボイス最適解.pdf」の前提知識。割合・期限の断定は資料の作成時点を必ず確認
- **用語再確認：経審（経営事項審査）の「P点（総合評定値）」は公共工事の入札参加資格の格付け根拠**。P点はX1（完成工事高）・X2（自己資本額/平均利益額）・Y（経営状況）・Z（技術力）・W（社会性等）の加重合成で算出され、公共工事を直接請負う建設業許可業者は受審必須。原価管理システム導入はY評点（経営状況分析）の改善文脈で訴求できる（出典：お役立ちツール_建設業許可と経営事項審査編.pdf／評点構成の詳細は資料外の一般知識）
- **用語再確認：「常用（常傭）」と「請負」は外注費・労務費の区分と偽装請負リスクに直結する**。請負＝完成物に対する対価（外注費・消費税の課税仕入対象）、常用＝時間・日数ベースの労務提供（実態が指揮命令下なら雇用に近く、外注費処理すると税務調査で給与認定・源泉徴収漏れを指摘されるリスク）。建設業の税務調査対策.pdfが扱う典型論点であり、どっと原価の支払区分設定の前提となる用語

- **現場・協力会社視点：制度対応（インボイス登録番号・電帳法）は法令要件のまま話しても響かず、現場に起きる実害・利得へ翻訳して初めて自分事になる**。「適格請求書の要件を満たす」でなく「請求書の突き返し・差し戻しが減る」「支払いが遅れない」「一人親方への発注判断で毎回悩まなくなる」に置き換える。経過措置控除率の縮小（07-27/08-03記録）も、元請の管理部門には税負担、現場・協力会社には発注先選定の話として別々に語る（有効値は資料作成時点／要確認の鮮度注記・06-17記録は両方に添える）

### 2026-08-18
- 商談支援メモは案件ごとに作らず、経営者向け／担当者向けの2系統テンプレと「どの資料をどちらに渡すか」のマッピング表を持つ。資料選定の判断が毎回発生せず、担当者層への訴求漏れで商談が最後に止まる事故も防げる
- 提案前の確認は機能説明から入らず、「今の日報・出面・材料伝票をそのまま入力元にできるか」の定型ヒアリングを先に通す。入力純増になる構成は導入後に必ず止まるため、この確認を通ってから機能の話に入る方が全体の商談工数が短い
- 制度対応（インボイス・電帳法）の説明は法令文を都度かみ砕かず、相手別（元請の管理部門＝税負担／現場・協力会社＝発注先選定と差し戻しの減少）の翻訳表から引く。説明の質が相手によってぶれず、準備時間もゼロになる

#### 1. 【工事原価4要素の区分判定と共通費配賦の設計】
**なぜ必要か**：完成工事原価報告書は**材料費・労務費・外注費・経費**の4要素で構成される。この区分を誤ると、経審のY評点（06-20記録）・税務調査の給与認定リスク（06-13記録の常用/請負）・工事別粗利分析のすべてが同時に狂う。どっと原価のマスタ設計は結局この4区分の定義戦であり、「どの支払をどこに入れるか」を決められないGenは導入支援の入口で止まる。

**具体的手法**：
- **積算体系の階層を固定して話す**：工事価格＝工事原価＋一般管理費等／工事原価＝純工事費＋現場管理費／純工事費＝直接工事費＋共通仮設費。クライアントが「原価」と言う時、この階層のどこを指すか（06-13記録の3階層と直交する軸）を必ず特定する
- **区分判定の順序を固定**：①完成物への対価か（Yes→外注費）→②自社雇用者への労務提供対価か（Yes→労務費）→③工事に直接投入するモノか（Yes→材料費）→④それ以外は経費。②で「指揮命令下の時間払い＝常用」（06-13記録）が外注費に紛れていないかを必ず検算する
- **共通費の配賦基準を先に1つ決める**：現場管理費・共通仮設費は工事別に直課できないため、配賦基準を「直接労務費基準／直接原価基準／出来高基準」から**1社1基準**で固定する。基準が混在すると工事別粗利が比較不能になる

**判断基準・数値ライン**（社内運用ライン。会計・税務の断定ではない）：
- 経費が直接工事費の **15%** を超える → 4要素の誤区分（外注費・材料費が経費に落ちている）を疑いマスタを検査
- 外注費比率 **60%** 超 → 労務費が外注費に紛れている可能性。常用/請負の実態確認（06-13記録）を優先
- 工事別に直課できている原価が全体の **80%** 未満 → 配賦依存が高すぎ、工事別収支の精度が担保できない
- 未配賦の共通費が残る → 「全社共通費として工事に配賦しない」と決めることも許容。**曖昧なまま按分するより明示的に除外**する方が予実の信頼性が高い

**実務テンプレート**：
```
【原価区分マスタ設計シート】
対象社：____ ／ 許可業種：____ ／ 元請下請の別：____ ／ 決算月：____（08-12記録）
配賦基準（1つに固定）：□直接労務費基準 □直接原価基準 □出来高基準
| 支払先・費目 | 実態（完成物/時間払い/モノ/その他） | 4要素区分 | 直課/配賦 | 判定根拠 | 要確認 |
|---|---|---|---|---|---|
| （例）A工務店・型枠一式 | 完成物への対価 | 外注費 | 直課 | 請負契約・出来高査定あり | － |
| （例）B氏・日当×人工 | 時間払い・自社指揮命令 | 労務費（要検討） | 直課 | 常用実態→外注費処理は否認リスク | 税理士確認 |
検算：経費／直接工事費＝__%（15%超→要検査） 外注費比率＝__%（60%超→常用混入疑い）
```
**期待効果**：マスタ設計の相談に「一般論」でなく判定順序と検算値で答えられる。誤区分に起因する税務・経審リスクを商談の場で先回り指摘でき、Genの立ち位置が資料案内役から設計相談役に上がる。

#### 2. 【原価差異分析 — 単価差異×数量差異の分解と赤字現場の早期検知】
**なぜ必要か**：どっと原価の中核価値は「実行予算vs発生原価」（06-17記録）の予実対比だが、差異が出た時に**なぜズレたか**を分解できないと「赤いのは分かるが手が打てない」で終わる。社長が知りたいのは「今動いている現場のうちどれが赤字か」（08-16記録）であり、その先の打ち手は単価要因か数量要因かで完全に別物になる。

**具体的手法**：
- **原価差異の2分解**（標準原価計算の定石を工事原価に適用）
  - 材料費差異＝**単価差異**（実行予算単価−実際単価）×実際数量 ＋ **数量差異**（実行予算数量−実際数量）×実行予算単価
  - 労務費差異＝**賃率差異**（予算賃率−実際賃率）×実際工数 ＋ **工数差異**（予算工数−実際工数）×予算賃率
  - 打ち手の振り分け：単価/賃率差異 → 購買・発注先選定・値上げ交渉（08-16記録の協力会社視点）／数量・工数差異 → 施工計画・段取り・手戻りの削減
- **二重進捗率チェック**：出来高進捗率（査定出来高÷請負金額）と原価進捗率（発生原価÷見込原価総額）を並べる。原価が出来高を先行していれば、出来高が上がる前に赤字が確定している
- **月次ローリング**：見込原価総額＝発生原価＋残工事原価。残工事原価を毎月組み直さず当初実行予算のまま置くと、差異が期末に一括で表面化する

**判断基準・数値ライン**（社内運用の警戒ライン）：
- 原価進捗率 − 出来高進捗率 ＝ **+5pt** → イエロー（現場ヒアリング）／**+10pt** → レッド（実行予算の組み直しと見込原価総額の再算定）
- 単一工種の原価が実行予算比 **110%** 超 → その工種を単価/数量に分解して要因特定
- 見込原価総額が請負金額の **95%** 到達 → 粗利5%割れ。手を打てる最終ライン
- 見込原価総額 ＞ 請負金額 → 赤字工事確定。スキル5（工事損失引当金）へエスカレーション
- 進捗率20%未満の初期段階の差異は**率でなく絶対額**で見る（母数が小さく率が暴れるため）

**実務テンプレート**：
```
【工事別 原価差異アラートシート（月次）】
工事名：____ 請負金額：____（税区分：税抜/税込・08-12記録） 決算月：____
出来高進捗率 __% ／ 原価進捗率 __% ／ 乖離 __pt（+5→黄 / +10→赤）
| 要素 | 実行予算 | 発生原価 | 差異 | うち単価(賃率)差異 | うち数量(工数)差異 | 主因 | 打ち手 |
|---|---|---|---|---|---|---|---|
| 材料費 |  |  |  |  |  |  | 購買/施工計画 |
| 労務費 |  |  |  |  |  |  | 賃率/段取り |
| 外注費 |  |  |  |  |  |  | 発注先/追加変更 |
| 経費 |  |  |  |  |  |  | － |
見込原価総額＝発生原価＋残工事原価＝____ ／ 対請負金額＝__%（95%→要対策 / 100%超→引当検討）
```
**期待効果**：「赤字が見える」から「赤字の原因が単価か数量かまで見える」へ訴求が一段上がる。工事別・今月時点で語れるため、社長視点（08-16記録）に直結する商談ストーリーになる。

#### 3. 【2024年問題の上限規制を数値で運用する — 36協定の残枠管理と原価跳ね返り試算】
**なぜ必要か**：2024年問題は現行の最大の導入動機（07-27記録）なのに、Genの記述は「労務可視化ニーズが高まる」という定性どまり。上限規制は**数字そのもの**で運用される制度であり、要件値を押さえていないと「何時間まで使えるのか」という現場の実質的な問いに答えられない。

**具体的手法**：
- **上限の数値要件を固定で押さえる**（労働基準法の時間外労働上限規制／建設業は2024年4月から適用）
  - 原則：月45時間・年360時間
  - 特別条項：年720時間以内／時間外＋休日労働が単月100時間未満／2〜6か月平均80時間以内／月45時間超は年6回まで
  - ※災害復旧・復興事業には一部規定の適用除外がある点、および要件値の最新は必ず確認する（06-17記録の鮮度注記を制度の適用範囲にも適用）
- **年度残枠管理へ翻訳**：技能者・現場代理人ごとに「年720の残枠」「月45超の残回数（年6回）」「直近6か月の平均80の余裕」を月次で可視化する。上限は年単位で効くため、**上期に使い切ると下期に工期が組めなくなる**
- **原価への跳ね返り試算**：残業抑制→①休日振替による工期延長→現場管理費（スキル1）の増加、②人員追加投入による労務費増、③外注化による外注費増、のいずれかに必ず変換される。「残業を減らす」は原価中立ではないことを金額で示す

#### 4. 【法定福利費の内訳明示と標準労務費 — 見積根拠を金額で組み立てる】
**なぜ必要か**：改正建設業法で「著しく低い労務費による見積・契約」の制限が進行（07-27記録）しているのに、Genは労務費の**妥当性を示す金額の組み立て方**を持っていない。見積書に法定福利費を内訳明示する標準見積書の運用は社会保険加入対策として定着しており、下請・協力会社との商談で最も具体的に効く論点。

**具体的手法**：
- **法定福利費は労務費に対して別枠で積算する**：法定福利費＝対象労務費 × 法定福利費率（事業主負担分）。対象は健康保険・介護保険・厚生年金・雇用保険（＋子ども・子育て拠出金）。**労災保険は元請一括加入が原則のため、下請の標準見積書の法定福利費には通常含めない**——ここを混ぜると見積が二重計上になる
- **率は年度・都道府県・業種で変動する**：事業主負担合計はおおむね労務費の**15%前後**が実務上の目安だが、**料率は毎年度改定されるため必ず当年度の料率で再計算**し、「目安値のまま断定しない」（06-17記録の鮮度注記を料率にも適用）
- **労務費の妥当性説明の3点セット**：①歩掛（数量あたり所要工数）②労務単価③法定福利費。この3つを分けて示せば「著しく低い労務費でない」根拠になる。どっと原価の実績工数データは①の自社歩掛を作る原資になる（これが原価管理システムの最も説明力ある訴求）
- 発注側（元請）／受注側（下請）で使う向きが逆になる：元請は「妥当性の検証」、下請は「値上げ・適正価格の根拠提示」。08-16記録の相手別翻訳表にこの2列を追加する

**判断基準・数値ライン**：
- 見積書に法定福利費の内訳明示が**無い** → 標準見積書の要件を満たさない。是正提案の入口
- 法定福利費／労務費の比率が **10%未満** → 対象保険の抜け（雇用保険のみ等）を疑う／**20%超** → 労災の二重計上や対象労務費の取り違えを疑う
- 自社歩掛のサンプルが同種工事 **3件未満** → 歩掛として使わず「参考値」と明示（母数が小さい数値の扱い・Dat連携の08-13記録と同じ原則）
- 労務単価が公表単価を大きく下回る → 「著しく低い労務費」の論点。断定せず **nori／税理士・行政確認**へ回す（08-13記録）

**実務テンプレート**：
```
【労務費 見積根拠 3点セット】
工種：____ 数量：____ 
① 歩掛：__人工/単位（自社実績n=__件／n<3は参考値）出典：どっと原価 実績工数
② 労務単価：____円/人工（税区分：____・08-12記録）
③ 所要労務費 ＝ ①×数量×② ＝ ____円
④ 法定福利費 ＝ ③ × __%（当年度料率／健保・介護・厚年・雇用＋子ども子育て拠出金。労災は元請一括のため除外）
   ※料率は年度改定。本表は__年度料率で算出／最新は要確認
見積計上額 ＝ ③＋④ ＝ ____円（法定福利費は内訳明示）
判定：④/③＝__%（10%未満→保険の抜け／20%超→労災二重計上を疑う）
```
**期待効果**：値上げ交渉・適正価格の相談に金額の組み立てで答えられる。改正建設業法の労務費論点で、制度解説でなく実務の見積書レベルまで降りられる唯一の存在になる。

#### 5. 【未成工事支出金の月次ローリングと工事損失引当金の計上判定】
**なぜ必要か**：06-20記録で未成工事支出金の存在は押さえたが、**期中にどう動かすか**と**赤字が見えた時に何を計上するか**が空白。工事損失引当金は「赤字が確定したら期をまたがず当期に損失を計上する」という会計処理で、経理・税理士が同席する商談で必ず出る論点。ここに答えられるかで、Genが経理層に信用されるかが決まる。

**具体的手法**：
- **月次ローリングの型**：見込原価総額＝発生原価（実績）＋残工事原価（毎月組み直し）。残工事原価を当初実行予算の残額で置くのは実質ノーコントロール。スキル2の二重進捗率チェックと同じデータで回す
- **工事損失引当金の判定**：工事契約から**損失が見込まれ、かつその金額を合理的に見積れる**場合、見込まれる損失額を引当計上する。計上額＝（見込原価総額 − 請負金額）− 既に計上済みの損失相当額
- **収益認識の枠組みと接続**：進捗度に応じた収益認識（原価比例法等／06-13記録）では、原価の見込みが変われば当期の収益額も動く。進捗度を合理的に見積れない場合は**原価回収基準**（回収が見込まれる発生費用と同額を収益計上）。決算月（08-12記録）に依存するため、期末をまたぐ工事は必ず決算月を先に確認する
- **会計処理の詳細は資料外の一般知識**として分離し、最終判断は顧問税理士へ（08-13記録のnori連携）

**判断基準・数値ライン**：
- 見込原価総額／請負金額 ＝ **95%超** → 粗利5%割れ。経理へ共有し引当の要否を検討
- **100%超** → 赤字見込み。合理的に見積れるなら工事損失引当金の検討対象
- 残工事原価を **3か月連続で更新していない** 工事 → ローリングが形骸化。予実対比の数字自体が信頼できない
- 期末をまたぎ、かつ工期 **6か月超** の工事 → 未成工事支出金の残高と進捗度の整合を必ず確認

**実務テンプレート**：
```
【期末またぎ工事 チェックシート】
決算月：__月（08-12記録） 工事名：____ 工期：__/__〜__/__
請負金額 ____ ／ 発生原価 ____ ／ 残工事原価（今月更新：更新日__） ____
見込原価総額 ____ ／ 対請負金額 __%（95%→注意 / 100%超→引当検討）
収益認識：□進捗度（原価比例法等） □原価回収基準（進捗度が合理的に見積れない）
期末振替：未成工事支出金 残高 ____ → 完成工事原価へ振替予定 __月
工事損失引当金：□不要 □検討中（見込額 ____） 
※会計処理の最終判断は顧問税理士へ／本シートは管理会計上の把握用（資料外の一般知識を含む）
```
**期待効果**：経理・税理士同席の商談で会話が成立する。「原価管理システムは現場の道具」から「決算数値の精度を上げる道具」へ訴求レイヤーが上がり、決裁者の関心と直結する。

#### 6. 【建設業法帳簿×施工体制台帳×電帳法 — 保存要件の統合マップ】
**なぜ必要か**：電帳法の電子取引データ保存は既に定着し、訴求軸は「対応可否」から「手間をどう減らすか」へ移った（08-03記録）。しかし建設業には**建設業法側の保存義務**（帳簿・営業に関する図書・施工体制台帳）が別建てで存在し、実務は「どの書類を何年、どの形式で残すか」で混乱する。ここを1枚のマップにできれば、＋Biz（電子受発注）の訴求が制度横断の必然性を持つ。

**具体的手法**：
- **3系統を分けて把握する**：①建設業法の帳簿・添付書類（営業所ごとに備付け・保存）②施工体制台帳／施工体系図／再下請負通知書（一定規模以上の下請発注時。公共工事は入契法により下請契約があれば作成義務）③電帳法（電子帳簿保存・スキャナ保存・電子取引データ保存の3系統／06-20記録）
- **保存年限は最長に揃えるのが実務解**：建設業法の帳簿は原則5年、発注者と締結した住宅の新築工事に係るものは10年。法人税法の帳簿書類は原則7年（欠損金がある事業年度は10年）。系統ごとに年限が違うため、**最長年限で一括保存**する運用がミスを構造的に消す
- **金額基準は改正で動く**：施工体制台帳の作成義務や特定建設業許可が必要となる下請発注総額の基準額（建築一式とそれ以外で別）は改正で変動するため、**必ず現行の基準額を確認**し、資料未記載なら「要行政・メーカー確認」（08-12記録）
- **＋Biz訴求への接続**：電子受発注は「注文書・請書・請求書が電子で一元保存される＝3系統の要件を1つの運用で満たす」点が価値。可否でなく**手間の削減量**で語る（08-05記録）

**判断基準・数値ライン**：
- 保存年限は **10年一括** を推奨ライン（5年/7年/10年の混在管理はミスの温床）
- 電子取引データの検索要件（取引年月日・取引金額・取引先の3項目）が**手作業のファイル名運用**で担保されている → 運用破綻リスク大。システム化の最有力訴求ポイント
- 下請発注総額が現行基準額の **80%** に到達する工事 → 施工体制台帳・特定許可（08-12記録）の要否を事前確認
- 紙と電子が混在し、同一取引が二重に存在する → 保存の一貫性が崩れる。原本の所在を1系統に決める

**実務テンプレート**：
```

| 書類 | 根拠系統 | 保存年限 | 受領/作成形式 | 保存場所 | 電帳法区分 | 要確認 |
```

### 🚫 新たに定義したNGパターン

1. **NG：4要素の区分を確認せず「原価が見える化できます」と訴求する** → 材料費・労務費・外注費・経費の区分定義とマスタ設計が決まっていない会社では、見えるようになるのは**誤区分された数字**。区分判定順序と検算値（経費15%／外注費60%）を先に通してから機能の話に入る。

2. **NG：原価差異を「予算比◯%オーバー」の1本の率だけで報告する** → 単価差異と数量差異では打ち手が購買と施工計画で完全に別。分解せずに率だけ出すのは「赤いですね」で終わる報告であり、原価管理システムの価値を自ら潰す。必ず2分解して主因と打ち手をセットで出す。

3. **NG：残業抑制を原価中立の話として説明する** → 上限規制対応は必ず工期延長（現場管理費増）・人員追加（労務費増）・外注化（外注費増）のいずれかに変換される。「残業を減らしましょう」で止めると、経営者には**利益を削る提案**にしか聞こえない。原価インパクトの試算を必ず添える。

4. **NG：法定福利費に労災保険を含めて積算する／目安率15%を当年度料率として断定する** → 労災は元請一括加入が原則で下請の標準見積書には通常含めず、含めると二重計上になる。料率は年度改定されるため、目安値のまま断定せず「__年度料率で算出／最新は要確認」を必ず付す。

5. **NG：赤字が見えた工事で、会計処理（工事損失引当金・収益認識）まで踏み込んで断定する** → Genの領分は管理会計上の把握までで、引当の要否・金額・計上時期は顧問税理士の判断。「見込原価総額が請負金額を超えた」という事実の提示と、「引当の検討対象になり得る／最終判断は税理士へ」の分離を厳守する。

6. **NG：保存年限を書類ごとの個別年限（5年/7年/10年）で管理する運用をそのまま推奨する** → 系統が3つ（建設業法・法人税法・電帳法）あり年限も起算も異なるため、個別管理は必ず事故る。最長年限での一括保存を推奨ラインとし、基準額・年限の現行値は必ず要確認を添える。

7. **NG：CCUS未導入・読取率の低い会社に就業履歴の原価連携を訴求する** → 一次データが無い／欠測だらけの状態で連携を語ると、導入後に「データが埋まらない」で運用が止まる。前提確認（導入状況・読取率80%）を通らない相手には、まず入力元の確認（08-16記録）へ話を戻す。

8. **NG：本v2で定義した閾値（15%・60%・+5pt/+10pt・95%・80%等）を、資料由来の数値や法令基準のように提示する** → これらはすべて**LET社内の運用判断ライン**であり、建設ドットウェブ社資料の記載でも法令の基準値でもない。対外提示時は「社内運用ライン」と明示し、資料出典（06-26記録）と混在させない。

### 📈 強化後の到達水準
- **原価表を読んで異常を指摘できる**：4要素の誤区分・配賦の偏り・単価/数量差異・見込原価総額の悪化を、検算値と警戒ラインで機械的に検出できる
- **制度を数字で運用できる**：上限規制の残枠、法定福利費の積算、保存年限の統合まで、制度解説でなく実務の計算と様式に落とせる
