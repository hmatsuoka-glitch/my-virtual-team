### 2026-06-13
- **用語再確認：「見積原価」「実行予算」「発生原価」は原価管理の3階層で混同厳禁**。見積原価＝受注前に積算した原価（利益計画の起点）、実行予算＝受注後に工事着手前に組み直す社内の原価目標（現場の予実管理の基準）、発生原価＝実際に支払・計上された原価。どっと原価の予実対比は「実行予算 vs 発生原価」であり、見積原価と比較すると受注後の原価低減努力が見えなくなる。クライアント説明時はどの原価を指すか必ず特定する
- **用語再確認：「工事進行基準/工事完成基準」は旧用語で、現行の収益認識会計基準では「履行義務の充足に係る進捗度に基づく収益認識（原価比例法等）」が正式な枠組み**。進捗度を合理的に見積れない場合は「原価回収基準」を適用。お役立ちツール_工事進行基準編.pdfの用語が旧基準ベースの場合、上場系・会計監査対象のクライアントには現行基準の呼称で補足する（※現行基準の詳細は資料外の一般知識）
- **用語再確認：インボイス制度の「経過措置」は免税事業者からの仕入に対する段階的控除のこと**。免税事業者（適格請求書発行事業者でない一人親方等）からの課税仕入は、本来仕入税額控除不可だが、経過措置により一定割合（80%→50%と段階縮小、最終的に控除廃止）の控除が認められる。建設業では下請・一人親方に免税事業者が多く、元請の控除減＝実質コスト増になる構図が「建設業インボイス最適解.pdf」の前提知識。割合・期限の断定は資料の作成時点を必ず確認
- **用語再確認：経審（経営事項審査）の「P点（総合評定値）」は公共工事の入札参加資格の格付け根拠**。P点はX1（完成工事高）・X2（自己資本額/平均利益額）・Y（経営状況）・Z（技術力）・W（社会性等）の加重合成で算出され、公共工事を直接請負う建設業許可業者は受審必須。原価管理システム導入はY評点（経営状況分析）の改善文脈で訴求できる（出典：お役立ちツール_建設業許可と経営事項審査編.pdf／評点構成の詳細は資料外の一般知識）
- **用語再確認：「常用（常傭）」と「請負」は外注費・労務費の区分と偽装請負リスクに直結する**。請負＝完成物に対する対価（外注費・消費税の課税仕入対象）、常用＝時間・日数ベースの労務提供（実態が指揮命令下なら雇用に近く、外注費処理すると税務調査で給与認定・源泉徴収漏れを指摘されるリスク）。建設業の税務調査対策.pdfが扱う典型論点であり、どっと原価の支払区分設定の前提となる用語

- **経営事項審査（経審）**: 公共工事を直接請け負う建設業許可業者が受審必須。P点（総合評定値）= X1（完成工事高）+ X2（自己資本・平均利益）+ Y（経営状況分析）+ Z（技術力）+ W（社会性等）の加重合成（06-13記録）。

#### 3-2. 建設業許可要件（5要件）

| 要件 | 内容 |
|------|------|
| 経営業務管理責任者（経管） | 建設業経営経験5年以上等 |
| 専任技術者 | 各営業所に業種ごとの資格・経験者を配置 |
| 誠実性 | 請負契約に不正・不誠実な行為をしないこと |
| 財産的基礎 | 一般：500万円以上の資金調達能力等／特定：資本金2,000万円以上・自己資本4,000万円以上等 |
| 欠格要件に該当しない | 破産・禁錮以上の刑等に該当しない |

#### 3-3. 下請法（建設工事は原則対象外・別法体系）

- **建設工事は下請法の適用対象外**。代わりに **建設業法** の下請取引適正化規定が適用される。
- 建設業法上の元請の義務:
  - 見積依頼時の必要事項提示（工事内容・工期・請負代金額など）
  - 書面での契約締結（工事内容・請負代金額・工期・支払方法等の必須記載事項）
  - 一括下請負の禁止（元請から下請への丸投げ禁止）
  - 特定建設業者による下請代金の50日以内支払等
- **中央建設業審議会の標準労務費勧告**（07-27記録）: 著しく低い労務費による見積・契約の制限。

#### 3-4. 労働安全衛生法（建設業関連）

- 元請の**統括安全衛生責任者**選任義務（下請含む常時50人以上の現場）
- **足場からの墜落防止措置**強化（手すり・幅木・安全帯（フルハーネス）等）
- **建設業のSTOP! 熱中症クールワークキャンペーン**による熱中症対策義務化の流れ
- 石綿（アスベスト）事前調査結果の労基署報告義務（2022年4月〜）

#### 3-5. 外国人労働者受入制度（建設業）

| 制度 | 特徴 | 建設業での位置付け |
|------|------|----------------|
| 技能実習制度（旧・移行期） | 3〜5年の技能移転 | 段階的廃止・育成就労制度へ移行中 |
| 育成就労制度（新制度） | 技能実習の後継。3年で特定技能1号へ | 建設分野の主要受入ルートへ |
| 特定技能1号 | 相当程度の知識・経験。通算5年上限 | 建設業11区分で受入拡大 |
| 特定技能2号 | 熟練した技能。在留更新可・家族帯同可 | 建設業も対象拡大済 |
| 特定活動（外国人建設就労者受入事業） | 経過措置的な受入枠 | 終期に向かう |

- **建設キャリアアップシステム（CCUS）**（08-03記録）: 技能者の就業履歴・保有資格を業界横断で蓄積。特定技能・育成就労の在留資格審査でも活用が進む。

### 📘 セクション5: 業界別特化Q&A集

#### 5-1. 建築工事業（一式）

- **原価特性**: 大型・長工期・多工種同時進行。実行予算の工種別粒度が命。
- **典型論点**: 追加変更工事の原価反映、下請多重構造の労務費配賦、竣工引渡時の完成工事高振替タイミング。
- **どっと原価訴求**: Neo + 3D View（BIM連携） + 経営分析。

#### 5-2. 土木工事業

- **原価特性**: 公共工事比率高い。歩掛計算・積算基準（国交省標準歩掛）が原価根拠。
- **典型論点**: 経審X1（業種別完成工事高）の適正申告、i-Construction 2.0対応、ICT建機導入費の原価計上。
- **どっと原価訴求**: Neo + 経営分析（経審Y評点シミュレーション） + 3D View（CIM連携）。

#### 5-3. 設備工事業（管・空調・衛生）

- **原価特性**: 材料費比率が高い。機器発注のタイミングと工事進捗のズレが資金繰りに影響。
- **典型論点**: 機器材料の先行発注管理、下請労務費との突合、メンテナンス契約の原価管理。
- **どっと原価訴求**: Ace + ＋Biz（電子発注） + 現場Pocket。

#### 5-4. 電気工事業

- **原価特性**: 資格者配置の労務コスト、材料の多品種少量、追加工事頻発。
- **典型論点**: 電気工事士の労務費単価管理、材料マスタの整備、追加工事の見積根拠。
- **どっと原価訴求**: Ace + ＋Biz + 現場Pocket。

#### 5-5. 内装仕上工事業

- **原価特性**: 短工期・多現場並行。労務費配賦の精度が利益直結。
- **典型論点**: 現場ごとの労務時間把握、材料余剰の原価吸収、下請一人親方のインボイス対応（08-03記録）。
- **どっと原価訴求**: Ace + 現場Pocket（現場入力の徹底）。

#### 5-6. 塗装工事業

- **原価特性**: 材料（塗料）在庫管理、天候リスクによる工期変動、外注比率高め。
- **典型論点**: 塗料の使用量原価配賦、雨天中止時の労務費、下請の常用/請負区分（06-13記録の偽装請負リスク）。
- **どっと原価訴求**: Ace + 現場Pocket。
